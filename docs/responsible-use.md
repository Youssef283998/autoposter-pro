# Responsible Use

AutoPoster Pro is a tool for scheduling and publishing content on social media platforms. You are responsible for complying with each platform's terms of service, developer policies and automation rules.

## Platform terms

By using AutoPoster Pro you agree to comply with:

- [Telegram Bot API Terms](https://core.telegram.org/bots/terms)
- [Discord Developer Terms](https://discord.com/developers/docs/legal)
- [Mastodon Terms of Service](https://joinmastodon.org/terms)
- [X Developer Agreement](https://developer.x.com/en/developer-terms)
- [LinkedIn Developer Agreement](https://developer.linkedin.com/legal/developer-terms)

## Built-in safeguards

AutoPoster Pro includes conservative defaults to help you stay within platform limits:

- Per-platform hourly and daily rate caps
- Randomized delays between posts to different accounts
- Duplicate prevention (content hash within a time window)
- Circuit breakers that pause failing platforms
- Configurable quiet hours

## What you should not do

- Use AutoPoster Pro to spam, harass or deceive
- Circumvent platform rate limits or automation restrictions
- Post content that violates any platform's content policies
- Use the tool for coordinated inauthentic behavior

## Your credentials

You use your own API keys and OAuth credentials. AutoPoster Pro never collects, transmits or stores your credentials on any server other than your own machine.
